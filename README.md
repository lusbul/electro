# Електроніка та приладобудування — прототип курсу КМАН

Структура: index.html — мапа 24 занять першого року; lessons/01.html — повністю інтерактивний навчальний прототип першого заняття. Інші уроки **не реалізовані**; другий рік поки в плані.

Розміщення: завантажте вміст архіву до кореня репозиторію GitHub Pages. Відкрийте index.html. Серверна частина не потрібна.

Вбудована модель закону Ома не є симулятором електричних кіл. Для фактичного складання й запуску схем учень переходить до Tinkercad Circuits; цей зовнішній сервіс потребує інтернету й може вимагати обліковий запис.

Збереження: localStorage цього браузера; може бути очищене. PDF — друк браузера з вибором «Зберегти як PDF», а не окремий генератор PDF.

Перевірено: створення файлів та структури. Не перевірено: браузерне тестування на смартфонах, фактичне виконання схеми Tinkercad, друк у різних браузерах.
