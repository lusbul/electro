Потенціометр і ШІМ: ручка яскравості

Аналоговий вхід, масштабування даних, PWM і керування світлом.

🎛️

Інженерна ситуація: світло, яке підлаштовується

Потрібно створити настільний індикатор, яскравість якого можна змінювати ручкою. Потенціометр повідомляє контролеру положення ручки, а ШІМ керує середньою потужністю світлодіода. Як зміниться світло, якщо збільшити частку часу HIGH?

Теорія: аналоговий вхід і ШІМ

Потенціометр — змінний резистор із рухомим контактом. У схемі подільника напруги крайні контакти підключають до 5 В і GND, середній — до A0. analogRead(A0) на Arduino Uno повертає число від 0 до 1023 для напруги від приблизно 0 до опорної (типово 5 В).

ШІМ (PWM) — швидке перемикання цифрового виходу між LOW і HIGH. analogWrite(9, value) на сумісному PWM-виводі Uno приймає значення 0–255: 0 — постійно LOW, 255 — постійно HIGH. Це не справжня аналогова напруга на виводі; середнє значення сигналу залежить від коефіцієнта заповнення. Для LED зазвичай це сприймається як зміна яскравості.

Функція map(raw, 0, 1023, 0, 255) масштабує діапазон. У прикладі нижче використовуються int, присвоєння =, додавання + і множення * у розрахунках.

Практика в Tinkercad · Керуйте яскравістю Arduino

  1. Додайте Arduino Uno, потенціометр, LED та резистор 330 Ω.
  2. Крайні контакти потенціометра підключіть до 5 V і GND, середній — до A0. LED: D9 → 330 Ω → анод LED → катод → GND.
  3. У текстовому редакторі коду введіть програму нижче, запустіть симуляцію та відкрийте Serial Monitor.
  4. Поверніть ручку на мінімум, середину та максимум. Порівняйте значення A0, PWM і яскравість.
const int potPin = A0;
const int ledPin = 9;
void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  int raw = analogRead(potPin);
  int pwm = map(raw, 0, 1023, 0, 255);
  analogWrite(ledPin, pwm);
  Serial.print("A0: ");
  Serial.print(raw);
  Serial.print("  PWM: ");
  Serial.println(pwm);
  delay(100);
}

Відкрити Tinkercad Circuits

У Serial Plotter графік може виглядати інакше, ніж у Serial Monitor, залежно від формату даних. Для Plotter виводьте числові значення в окремому простому форматі, наприклад Serial.println(raw);.
