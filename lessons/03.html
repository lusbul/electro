Ситуація: маячок для лабораторного приладу

Прилад має блимати світлодіодом, щоб повідомляти: живлення увімкнено. Як змусити мікроконтролер виконувати команду знову й знову? Спочатку передбачте, як зміниться сигнал, якщо зменшити паузу.

Теорія: Arduino, вихід і програма

Arduino Uno — навчальна плата з мікроконтролером. Цифровий вихід може встановлювати рівні LOW або HIGH. У функції setup() налаштовують режим виводу; loop() повторюється, поки плата працює. pinMode(pin, OUTPUT) налаштовує вивід, digitalWrite(pin, HIGH) задає високий рівень, а delay(ms) зупиняє виконання на вказані мілісекунди.

Зовнішній LED потребує послідовного резистора. Довга ніжка типового LED — анод (+), коротка — катод (−); орієнтуйтеся також на пласку грань корпусу. Для навчальної схеми використайте 220–330 Ω.

Arduino D8 → ▭ 330 Ω → 💡 анод LED → катод LED → GND

Це низьковольтна схема. Не використовуйте мережеву напругу 230 В.

LED вимкнений

Практика в Tinkercad · Запустіть справжній код Arduino

  1. Створіть схему з Arduino Uno, LED та резистором 330 Ω; з’єднайте D8 → резистор → анод LED, катод → GND.
  2. У розділі Code перейдіть у текстовий режим, введіть код нижче та запустіть симуляцію.
  3. Замініть обидві паузи на 200 мс, потім зробіть 100 мс HIGH та 900 мс LOW. Порівняйте сигнали.
const int ledPin = 8;
void setup() {
  pinMode(ledPin, OUTPUT);
}
void loop() {
  digitalWrite(ledPin, HIGH);
  delay(500);
  digitalWrite(ledPin, LOW);
  delay(500);
}
